# Open-Source AI Security Tools Effectiveness Research

Research status: INITIALIZATION

No effectiveness conclusions are available yet.

This repository will contain a public, reproducible, evidence-backed study of whether open-source AI security tools provide measurable security value under benign, adversarial, multilingual, out-of-distribution, and operational test conditions.

## Current phase

Repository initialization and execution-environment audit.

## Safety scope

All experiments must use controlled local or isolated environments, synthetic or openly licensed data, fictitious credentials and non-destructive payloads. This project does not authorize testing third-party services or publishing weaponizable bypass instructions.
